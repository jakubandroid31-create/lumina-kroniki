## Polski

### O grze
**LUMINA** to JRPG 2D z widokiem z góry, w stylu pixel-art znanym z klasycznych gier o łapaniu stworzeń na przenośne konsole — ale **wszystko jest oryginalne**: stworzenia, nazwy, krainy i muzyka. Wędrujesz przez dziesięć krain, łapiesz i trenujesz stworzenia, pokonujesz trenerów i strażników krain, a przy kapliczkach (w klimacie ognisk z Dark Souls) odpoczywasz, zapisujesz grę i podróżujesz. Menu i ustawienia mają mroczny, złoto-czarny styl, a okna w grze — jasne, zaokrąglone ramki jak w klasycznych JRPG. Gra działa po polsku i po angielsku, w przeglądarce na komputerze i telefonie, jako aplikacja na Androida i jako „aplikacja” z ekranu głównego na iPhonie.

### Dziesięć krain
Krainy odblokowują się po kolei — każda ma własny wygląd, stworzenia, dwóch trenerów, bossa, kapliczki, skrzynie, zapiski fabularne i własny utwór muzyczny.

| | Kraina |
|---|---|
| I | **Łąki Świtu** — kwieciste pola i płatki na wietrze |
| II | **Szepczący Las** — gęsty bór pełen świetlików |
| III | **Kryształowe Jaskinie** — groty pełne lśniących kryształów |
| IV | **Wybrzeże Mew** — plaże, muszle i fale |
| V | **Pustynia Słońca** — rozgrzane piaski i kaktusy |
| VI | **Wulkan Popiołów** — lawa i żar |
| VII | **Mroźne Szczyty** — mróz i śnieżyca |
| VIII | **Nawiedzone Mokradła** — mgła i martwe drzewa |
| IX | **Wieża Niebios** — wyspy wśród chmur |
| X | **Cytadela Zmierzchu** — ostatnia twierdza i walka finałowa |

### Funkcje
- **9 typów żywiołów** (zwykły, ogień, woda, roślina, wolt, lód, ziemia, cień, światło) z tabelą skuteczności, statusy (oparzenie, trucizna, paraliż, sen, zamrożenie), wzmocnienia i osłabienia.
- **53 oryginalne formy stworzeń**: 9 form startowych (3 startery × 3 etapy), 33 dzikie gatunki i 11 form bossów.
- **Łapanie stworzeń** kulami o różnej mocy; drużyna do 6 stworzeń i **schowek** na pozostałe.
- **Ewolucje** — trzy startowe stworzenia mają po dwie ewolucje, wiele dzikich też ewoluuje; nauka nowych ruchów z poziomem.
- **Trenerzy** w każdej krainie i **bossowie** strzegący przejścia dalej.
- **Kapliczki** — leczą drużynę, zapisują grę, dają dostęp do schowka i szybkiej podróży między odblokowanymi krainami.
- **Bestiariusz** — spotkane i złapane gatunki.
- **Sklep**, skrzynie ze skarbami, mikstury, eterki, ożywienia, lekarstwa.
- **5 slotów zapisu**, autozapis, **eksport i import** zapisu do pliku `.json` (przeniesiesz grę między urządzeniami).
- **Kamera**: przybliżanie/oddalanie i **obrót o pełne 360°**, przesuwanie.
- Działa **offline** po pierwszym uruchomieniu (service worker).

### Ustawienia
- **Gra:** język (PL/EN), szybkość tekstu, automatyczne przewijanie tekstu w walce, poziom trudności, częstość spotkań, animacje walki, autozapis.
- **Obraz:** rozdzielczość renderowania (auto, 480×270 … 1920×1080), skalowanie (dopasuj / całkowite / rozciągnij), jasność, wstrząsy ekranu, linie skanowania (CRT), cząsteczki, licznik FPS, pełny ekran.
- **Dźwięk:** głośność ogólna, muzyki i efektów, wyciszanie w tle, własna muzyka z plików.
- **Sterowanie:** zmiana wszystkich klawiszy (dwa na akcję) i przycisków pada, martwa strefa gałek, wibracje pada, kliknij-i-idź myszą, kamera myszą, odwrócony zoom, ruch względem obróconej kamery, szybkość obrotu, rodzaj podpowiedzi przycisków.
- **Dotyk:** przyciski dotykowe (auto/wł./wył.), rozmiar, przezroczystość, tryb leworęczny, wibracje.

### Sterowanie
Wszystkie klawisze i przyciski pada można zmienić w **Ustawieniach → Sterowanie**.

- **Klawiatura (domyślnie):**

  | Akcja | Klawisze |
  |---|---|
  | Ruch | strzałki / WASD |
  | Zatwierdź, rozmawiaj, otwieraj | Enter / Z |
  | Wstecz | Backspace / X |
  | Menu (pauza) | Esc / C |
  | Bieg | Shift |
  | **Obrót kamery** | Q / E |
  | Zoom | + / − (także na klawiaturze numerycznej) |
  | Reset kamery | R |
- **Mysz:**
  - **kliknij, aby iść** we wskazane miejsce (kliknięcie postaci lub skrzyni – podejdź i użyj);
  - **przeciąganie** lewym przyciskiem – przesuwanie kamery;
  - **kółko** – zoom;
  - **przeciąganie prawym przyciskiem** (lub Q/E) – **obrót kamery o 360°**;
  - w menu: najechanie zaznacza, klik wybiera, prawy klik – wstecz.
- **Dotyk (telefon/tablet):** wirtualny **D-pad**, przyciski **A/B**, przyciski menu i biegu, **przyciski kamery** (obrót, zoom, reset); **szczypanie** dwoma palcami – zoom, **obrót dwoma palcami** – obrót kamery; stuknięcie w mapę – idź tam.
- **Pad (gamepad, domyślnie):** lewa gałka / krzyżak – ruch; **A** – zatwierdź; **B** – wstecz (przytrzymany – bieg); **X** – bieg; **Start / Y** – menu; **LB / RB** – obrót kamery; **LT / RT** – zoom; **L3** (lub Select) – reset kamery; **prawa gałka** – sterowanie kamerą. **Wszystkie przyciski można przypisać na nowo**, a martwą strefę gałek ustawić w opcjach.

### Jak działa publikacja na GitHub Pages
Workflow `.github/workflows/pages.yml` uruchamia się po każdym pushu do `main` (zmiany w `src/`, `web/` lub `build.py`). Najpierw wykonuje `python3 build.py`, który skleja moduły z `src/` w `web/index.html`, a potem wysyła cały folder `web/` na gałąź **`gh-pages`**. GitHub wyświetla tę gałąź pod adresem https://jakubandroid31-create.github.io/lumina-kroniki/.
**Jednorazowe ustawienie w repozytorium (po pierwszym uruchomieniu workflow):** **Settings → Pages → Source: Deploy from a branch → `gh-pages` / root**.

Workflow `.github/workflows/android.yml` przy każdym pushu do `main` również buduje `web/index.html`, tworzy projekt Capacitor, generuje ikony, ustawia orientację poziomą i tryb pełnoekranowy (`scripts/patch-android.js`), buduje APK i publikuje go w wydaniu **`najnowsza`** jako `lumina-kroniki.apk` (link „latest/download” zawsze wskazuje najnowszy plik). Tag `v*` (np. `git tag v0.2.0 && git push --tags`) tworzy osobne wydanie z numerem wersji. Plik APK jest też dostępny jako artefakt w zakładce **Actions**.
To wersja *debug* — do testów i dzielenia się. Do Google Play potrzebna jest podpisana wersja *release* (AAB).

### Muzyka
Cała muzyka to **oryginalny chiptune generowany proceduralnie** przez kod gry (Web Audio) — bez nagrań i cudzych melodii, udostępniony jako **CC0**. Osobny utwór ma menu, prolog, **każda z 10 krain**, walka z dzikim stworzeniem, walka z trenerem, **boss**, walka finałowa i zakończenie; do tego dżingle (zwycięstwo, nowy poziom, złapanie, ewolucja…).

**Własna muzyka:** wrzuć pliki mp3/ogg do `web/music/` i wpisz je do `web/music/tracks.json`, np.:
```json
{ "menu": "menu.mp3", "lvl1": "laki.ogg", "battle": "walka.mp3", "boss": "boss.mp3" }
```
Klucze: `menu`, `story`, `lvl1`…`lvl10`, `battle`, `trainer`, `boss`, `final`, `ending`. Brakujące utwory nadal generuje gra. Szczegóły i darmowe źródła (OpenGameArt CC0, Pixabay Music): [`web/music/README.md`](web/music/README.md). Pamiętaj o licencjach i podaniu autorów.

### Budowanie
```bash
python3 build.py          # src/ → web/index.html (zbudowany plik jest też w repozytorium)
# podgląd lokalny:
cd web && python3 -m http.server 8000   # http://localhost:8000
```
APK lokalnie (Node.js 20, JDK 17, Android SDK):
```bash
npm install
npm run android:init      # tworzy android/, ikony, orientację poziomą i pełny ekran
npm run android:apk       # android/app/build/outputs/apk/debug/app-debug.apk
npm run android:open      # albo otwórz w Android Studio
```
Po zmianach w `src/` uruchom `npm run android:sync` (buduje index.html i kopiuje do projektu).

## English

### About the game
**LUMINA** is a top-down 2D JRPG in the pixel-art style of classic handheld creature-catching games — but **everything is original**: creatures, names, realms and music. You travel through ten realms, catch and train creatures, defeat trainers and realm guardians, and at shrines (in the spirit of Dark Souls bonfires) you rest, save and travel. Menus and settings use a dark gold-on-black style, while in-game windows are bright rounded frames like classic JRPGs. The game is in Polish and English and runs in the browser on desktop and mobile, as an Android app, and as a home-screen “app” on iPhone.

### The ten realms
Realms unlock one after another — each has its own look, creatures, two trainers, a boss, shrines, chests, lore notes and its own music track.

| | Realm |
|---|---|
| I | **Dawnlight Meadows** — flower fields and petals on the wind |
| II | **Whispering Woods** — a dense wood full of fireflies |
| III | **Crystal Caverns** — grottoes of glittering crystals |
| IV | **Gullwing Coast** — beaches, shells and waves |
| V | **Sunscar Desert** — scorching sands and cacti |
| VI | **Ashen Volcano** — lava and embers |
| VII | **Frostpeak Heights** — frost and blizzards |
| VIII | **Haunted Mire** — fog and dead trees |
| IX | **Skyward Spire** — islands among the clouds |
| X | **Twilight Citadel** — the last fortress and the final battle |

### Features
- **9 elemental types** (normal, fire, water, grass, volt, ice, earth, shadow, light) with an effectiveness chart, status effects (burn, poison, paralysis, sleep, freeze), buffs and debuffs.
- **53 original creature forms**: 9 starter forms (3 starters × 3 stages), 33 wild species and 11 boss forms.
- **Catching creatures** with orbs of different strength; a party of up to 6 and a **storage box** for the rest.
- **Evolutions** — the three starters each evolve twice, many wild creatures evolve too; new moves are learned on level-up.
- **Trainers** in every realm and **bosses** guarding the way forward.
- **Shrines** — heal your party, save the game, access storage and fast-travel between unlocked realms.
- **Bestiary** — species seen and caught.
- **Shop**, treasure chests, potions, ethers, revives, cures.
- **5 save slots**, autosave, **export & import** saves as a `.json` file (move your game between devices).
- **Camera**: zoom in/out, **full 360° rotation**, panning.
- Works **offline** after the first launch (service worker).

### Settings
- **Game:** language (PL/EN), text speed, auto-advance text in battle, difficulty, encounter rate, battle animations, autosave.
- **Display:** render resolution (auto, 480×270 … 1920×1080), scaling (fit / integer / stretch), brightness, screen shake, scanlines (CRT), particles, FPS counter, fullscreen.
- **Sound:** master, music and effects volume, mute in background, custom music files.
- **Controls:** rebind every key (two per action) and gamepad button, stick deadzone, gamepad rumble, mouse click-to-move, mouse camera, inverted zoom, camera-relative movement, rotation speed, button-hint style.
- **Touch:** on-screen buttons (auto/on/off), size, opacity, left-handed layout, vibration.

### Controls
Every key and gamepad button can be changed in **Settings → Controls**.

- **Keyboard (defaults):**

  | Action | Keys |
  |---|---|
  | Move | arrows / WASD |
  | Confirm, talk, open | Enter / Z |
  | Back | Backspace / X |
  | Menu (pause) | Esc / C |
  | Run | Shift |
  | **Rotate camera** | Q / E |
  | Zoom | + / − (numpad too) |
  | Reset camera | R |
- **Mouse:**
  - **click to move** to a spot (clicking a character or chest walks up and uses it);
  - **left-drag** – pan the camera;
  - **wheel** – zoom;
  - **right-drag** (or Q/E) – **rotate the camera 360°**;
  - in menus: hover selects, click confirms, right-click goes back.
- **Touch (phone/tablet):** virtual **D-pad**, **A/B** buttons, menu and run buttons, **camera buttons** (rotate, zoom, reset); **pinch** with two fingers to zoom, **twist** two fingers to rotate the camera; tap the map to walk there.
- **Gamepad (defaults):** left stick / D-pad – move; **A** – confirm; **B** – back (hold – run); **X** – run; **Start / Y** – menu; **LB / RB** – rotate camera; **LT / RT** – zoom; **L3** (or Select) – reset camera; **right stick** – camera control. **Every button is fully rebindable**, and the stick deadzone is adjustable.

### How the GitHub Pages deploy works
The `.github/workflows/pages.yml` workflow runs on every push to `main` (changes in `src/`, `web/` or `build.py`). It first runs `python3 build.py`, which concatenates the modules in `src/` into `web/index.html`, and then force-pushes the whole `web/` folder to the **`gh-pages`** branch. GitHub serves that branch at https://jakubandroid31-create.github.io/lumina-kroniki/.
**One-time repository setting (after the workflow has run once):** **Settings → Pages → Source: Deploy from a branch → `gh-pages` / root**.

The `.github/workflows/android.yml` workflow also rebuilds `web/index.html` on every push to `main`, creates the Capacitor project, generates icons, sets landscape orientation and immersive fullscreen (`scripts/patch-android.js`), builds the APK and publishes it to the **`najnowsza`** (“latest”) release as `lumina-kroniki.apk` (the “latest/download” link always points to the newest file). A `v*` tag (e.g. `git tag v0.2.0 && git push --tags`) creates a separate versioned release. The APK is also available as an artifact under **Actions**.
This is a *debug* build — for testing and sharing. Google Play requires a signed *release* build (AAB).

### Music
All music is **original chiptune generated procedurally** by the game code (Web Audio) — no recordings and no borrowed melodies — released as **CC0**. There is a separate track for the menu, the prologue, **each of the 10 realms**, wild battles, trainer battles, **bosses**, the final battle and the ending, plus jingles (victory, level up, catch, evolution…).

**Custom music:** put mp3/ogg files in `web/music/` and list them in `web/music/tracks.json`, e.g.:
```json
{ "menu": "menu.mp3", "lvl1": "meadow.ogg", "battle": "battle.mp3", "boss": "boss.mp3" }
```
Keys: `menu`, `story`, `lvl1`…`lvl10`, `battle`, `trainer`, `boss`, `final`, `ending`. Missing tracks are still generated by the game. Details and free sources (OpenGameArt CC0, Pixabay Music): [`web/music/README.md`](web/music/README.md). Respect licenses and credit the authors.
