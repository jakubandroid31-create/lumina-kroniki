# Własna muzyka / Custom music

## Polski

Domyślnie LUMINA gra **własną, oryginalną muzykę chiptune generowaną na żywo** przez kod gry (Web Audio) — nic tu nie trzeba wrzucać.
Jeśli chcesz, możesz podmienić dowolne utwory na własne pliki **mp3** lub **ogg**:

1. Wrzuć pliki do tego folderu (`web/music/`).
2. Wpisz je do `tracks.json` — klucz to miejsce w grze, wartość to nazwa pliku:
   ```json
   {
     "menu": "menu.mp3",
     "lvl1": "laki.ogg",
     "battle": "walka.mp3",
     "boss": "boss.mp3"
   }
   ```
3. Utwory, których nie wpiszesz, dalej będą generowane przez grę.
4. W **Ustawieniach → Dźwięk** musi być włączona opcja „Własna muzyka” (domyślnie włączona).

Dostępne klucze:

| Klucz | Kiedy gra |
|---|---|
| `menu` | ekran tytułowy i menu |
| `story` | prolog i scenki fabularne |
| `lvl1` … `lvl10` | kraina I … X |
| `battle` | walka z dzikim stworzeniem |
| `trainer` | walka z trenerem |
| `boss` | walka z bossem krainy |
| `final` | walka finałowa |
| `ending` | zakończenie i napisy |

Utwory się zapętlają, więc najlepiej brzmią pliki przygotowane do zapętlenia (loop).

**Skąd brać darmową muzykę:**
- [OpenGameArt.org](https://opengameart.org/) — filtruj po licencji **CC0** (można używać bez podawania autora, choć warto).
- [Pixabay Music](https://pixabay.com/music/) — licencja Pixabay, darmowa także w grach.
- [FreePD](https://freepd.com/) — muzyka w domenie publicznej.
- [Kevin MacLeod / incompetech](https://incompetech.com/) — CC BY (wymaga podania autora).

**Zawsze sprawdzaj licencję i podawaj autorów** — np. dopisz ich w tym pliku albo w README projektu. Nie wrzucaj utworów z innych gier ani płyt, do których nie masz praw.

## English

By default LUMINA plays **its own original chiptune music, generated live** by the game code (Web Audio) — you don't need to put anything here.
If you like, you can replace any track with your own **mp3** or **ogg** files:

1. Put the files in this folder (`web/music/`).
2. List them in `tracks.json` — the key is the place in the game, the value is the file name (see the example above).
3. Tracks you don't list are still generated by the game.
4. **Settings → Sound → “Custom music”** must be on (it is on by default).

Keys: `menu`, `story`, `lvl1` … `lvl10` (realm I … X), `battle` (wild creature), `trainer`, `boss` (realm boss), `final` (final battle), `ending` (ending & credits).
Tracks loop, so loop-ready files sound best.

**Where to find free music:** [OpenGameArt.org](https://opengameart.org/) (filter by **CC0**), [Pixabay Music](https://pixabay.com/music/), [FreePD](https://freepd.com/) (public domain), [incompetech](https://incompetech.com/) (CC BY — attribution required).

**Always check the license and credit the authors** (e.g. list them in this file or in the project README). Don't add tracks from other games or albums you don't have rights to.
